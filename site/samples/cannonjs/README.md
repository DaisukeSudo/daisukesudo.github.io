## Demo: Dusk Drive

[Dusk Drive](./demo/) は、記事の Step3 の車を発展させた全画面のデモです。

- 夕暮れの砂丘を走り回り、積まれた箱のピラミッドやタワーを崩して遊べます。空からはボールや箱が光の軌跡を残して降ってきます。
- 車は `RaycastVehicle` によるサスペンション付きの 4WD、地形は `Heightfield` で作っています。
- 衝突すると火花が散り、走ると砂ぼこりが舞います。
- 操作は WASD / 矢印キーで走行、Space でブレーキ、Shift でブースト、R でリセット、ドラッグで視点の変更です。
- スマホでは画面にタッチボタンが表示されます（Step3 はキーボード専用でした）。
- 横転したり動けなくなったりすると、自動で立て直します。
