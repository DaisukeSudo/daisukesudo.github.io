## Demo: Neon Cube

[Neon Cube](./demo/) は、記事で作った「回る箱」を仕上げた全画面のデモです。

- 夕焼けの水面にネオンに光るキューブが浮かび、まわりを光の輪が回ります。
- 水面は `Reflector` に独自のシェーダーを組み合わせ、映り込みを揺らしています。空・星・山並みもシェーダーで描いています。
- `EffectComposer` と `UnrealBloomPass` で光をにじませています。
- ドラッグで視点を回し、キューブをクリック（タップ）すると水面に波紋が広がります。
